# Где твой сталкер? — интерактивный лонгрид

Готовый адаптивный сайт на **HTML + CSS + чистом JavaScript**. Исходный цельный SVG **не накладывается** на фон: текст, сообщения, интерфейс, кнопки, таймеры и сетки фотографий созданы HTML и CSS. Из исходных файлов используются только отдельные фотографии и звук.

## Запуск

Откройте папку в Visual Studio Code и запустите **Live Server** на `index.html`. Также можно воспользоваться локальным сервером, например:

```bash
python -m http.server 8000
```

Перейдите в браузере на `http://localhost:8000`. Для запроса разрешений на камеру/микрофон браузеру нужен защищённый контекст: **HTTPS** или **localhost**. При открытии `file://` такие запросы могут не работать.

## Управление

- Компьютер: колесо мыши, тачпад, стрелки или Page Down / Page Up.
- Телефон: свайп вверх или вниз.
- Чаты: одно продвижение прокруткой = одно новое сообщение (включая собственные ответы). В двух первых чатах кнопка «Заблокировать» переводит дальше. В последнем чате она **не реагирует**; после конца переписки понадобится ещё одна прокрутка.
- Фотозадания: 1-й блок — нижний левый; 2-й — верхний левый; 3-й — нижний левый **и** верхний правый. Пока ответы не выбраны, вперед перейти нельзя. Ошибки показывают подсказку.
- Вопросы: первый выбор показывает «Точно?», повторный переводит дальше.
- Таймеры: 15 и 10 секунд; цифры обновляются каждую секунду.
- Информационные экраны: текст печатается, после чего предусмотрен дополнительный шаг прокрутки перед переходом.
- Уведомления: появляются с задержкой, сопровождаются MP3-звуком, открывают следующий экран по нажатию.

**Важно для звука:** современные браузеры часто блокируют воспроизведение до первого взаимодействия с сайтом. Нажмите на экран или включите «Звук» вверху справа. Файл `assets/notification.mp3` — предоставленная запись.

**Камера и микрофон:** разрешения запрашиваются по мере достижения соответствующих сцен. При согласии медиапоток немедленно останавливается; сайт ничего не записывает, не хранит и не передаёт. При отказе история продолжается. Дополнительные подсказки и кнопки запроса разрешений намеренно отсутствуют: остаётся только стандартный диалог браузера. На сцене микрофона надпись появляется через 3,1 секунды.

## Изменения во второй версии

- Приведены к единому виду все входящие и исходящие сообщения; время выровнено внутри пузыря без `float`, анимация раскрытия плавная.
- На главном экране уменьшены и отцентрированы элементы, глазок переключается быстрее.
- Второй фотоблок заменён фотографиями из нового `Frame(1).svg` (каждая картинка отдельный кликабельный файл).
- Текстовые последовательности объединены с соседними информационными и вопросными сценами, а три реплики «Нет, это уже слишком / Полина...» печатаются и стираются в одном месте.
- В реплике «Ха-ха, ладно, расслабься...» красным выделены отдельные буквы, складывающиеся в фразу «НЕ ВЕРЬ ЕМУ», как в макете.
- «Дай мне тебя увидеть» увеличено, а вопрос о микрофоне появляется с задержкой.

## Структура

- `index.html` — все тексты, экраны, элементы и фотографические задачи.
- `styles.css` — внешний вид и адаптивность.
- `script.js` — интерактивность, задержки, прокрутка, глитч, таймеры, разрешения.
- `assets/` — исходные изображения глазка, фото из трёх макетов и звук.

## Изменение параметров

- Задержка первого уведомления: `script.js` → `enterScene()` → `4000`.
- Скорость печати: `script.js` → `typeElement()` → `29` миллисекунд на символ (длинные тексты автоматически ограничены 10 секундами).
- Анимация глазка: `script.js` → `startEyeGlitch()`.
- Время таймера: `data-seconds="15"` / `data-seconds="10"` в `index.html`.
- Правильные ответы фотозаданий: `data-correct` (нумерация: 0 — верхнее левое, 1 — верхнее правое, 2 — нижнее левое, 3 — нижнее правое).
- Цветовые переменные: начало `styles.css`.

Шрифты используются системные (Arial, Helvetica) — в исходных SVG надписи превращены в контуры и не содержат файла шрифта.
